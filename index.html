Cara Bermain di NES5 NETWORK

Hanya butuh waktu kurang dari 1 menit untuk memulai petualanganmu bersama kami!

01

Buka Minecraft

Jalankan Minecraft Java Edition versi 1.8 hingga versi terbaru 1.21 (Direkomendasikan versi 1.20.6).

02

Pilih Multiplayer

Masuk ke menu Multiplayer, lalu klik tombol Add Server (Tambah Server).

03

Masukkan IP Server

Ketik alamat IP java.nss.biz.id pada kolom Server Address, lalu klik Done.

04

Klik Join & Mainkan!

Pilih server NES5 NETWORK pada daftar server kamu dan klik Join Server. Selamat bermain!
